# mepbimcodex

A simple browser-based **MEP Project Viability Calculator**.

## What it calculates
- Project cost from:
  - Project area (sqm)
  - Construction cost (per sqm or total)
- MEP revenue using MEP fee (%)
- Discipline-wise fee split using weightage (%) for:
  - Electrical
  - Plumbing
  - HVAC
  - Firefighting
- Expense model with staffing roles (hourly/daily/weekly/monthly) and overheads
- One-time project expenses
- Viability metrics:
  - Total expenses
  - Profit / loss
  - Profit margin
  - Break-even MEP fee
  - MEP fee required for target margin
- Scenario save/load/delete in browser storage
- CSV summary export

## Run
Open `index.html` in any browser.

## Layout notes
- The calculator is responsive.
- Wide tables use horizontal scrolling on small screens so text and inputs are not cut off.
